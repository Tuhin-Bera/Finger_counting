This project uses OpenCV, MediaPipe, and a custom hand tracking module to count the number of raised fingers detected via webcam in real-time. Based on the number of fingers shown, it overlays an image and displays the count on the screen.

📌 Features
Real-time hand detection using webcam

Finger counting using landmark detection

Displays corresponding image for 0–5 fingers (custom images can be added)

FPS counter to monitor performance
